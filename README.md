## 报告里有什么

1. 15 张截图的识别结果（含 1 张撤单、1 张重复、1 张无法识别）
2. 8 场去重比赛的半场/全场比分、胜平负与让球彩果
3. 逐张票的注数、连乘赔率、理论奖金核对和未中原因
4. 同一场在多张票上的重复暴露
5. 可以下次执行的投注纪律（带数字上限）

## 口径

- 结算按竞彩足球 90 分钟（含伤停补时）
- 优先使用票面购买赔率
- 截止赔率若无法从官方截止表确认，报告里会写「数据缺失」，不会编造临场升降
- 不把亚洲盘或欧洲公司赔率当作竞彩固定奖金
